# Concepts

* [Corpus Engineer](corpus-engineer.md) - Use for work on the corpus/RAG layer — sourcing texts, licensing/provenance, ingestion via xberg, retrieval, and the framework artifacts. Knows the ship/reference model cold.
* [Rust Engine Dev](rust-engine-dev.md) - Use for the Rust engine — the domain model (monomyth-core), hybrid generation (monomyth-gen), and frontends. Cares about determinism, a clean serializable contract, and clippy-strict code.
